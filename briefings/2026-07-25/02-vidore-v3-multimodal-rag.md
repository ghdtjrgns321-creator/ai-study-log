# 오늘의 AI 개념: 멀티모달 RAG 벤치마크 ViDoRe V3(Visual Document Retrieval V3)

> 작성일: 2026-07-25 · 분류: ai-concept

## 한 줄 정의

ViDoRe V3는 표·차트·이미지가 뒤섞인 실제 문서에서 AI가 얼마나 정확히 정보를 찾아 답하는지를, 사람이 직접 검증한 대규모 데이터로 평가하는 새 시험 기준이다.

## 쉬운 설명

RAG(검색증강생성, Retrieval-Augmented Generation)는 AI가 답을 지어내지 않고 외부 문서를 먼저 찾아본 뒤 그 내용을 근거로 답하게 하는 방식이다(2026-07-06 "에이전틱 RAG" 편에서 기본 개념을 다뤘다). 기존 RAG 평가는 대부분 순수 텍스트 문서를 대상으로 했다.

문제는 실제 업무 문서 상당수가 텍스트만으로 안 된다는 점이다. 재무제표의 표, 계약서의 도장, 보고서 안의 차트는 글자를 추출(OCR)하는 순간 표의 구조나 그림의 의미가 사라지기 쉽다. ViDoRe(Visual Document Retrieval)는 이런 "시각적으로 복잡한 문서"를 있는 그대로 평가 대상으로 삼는 벤치마크 계열이다.

비유하자면 기존 RAG 시험이 "글로만 된 시험지"를 잘 푸는지 확인했다면, ViDoRe는 "표와 그림이 섞인 시험지"를 얼마나 잘 읽어내는지 확인하는 시험이다. 문서를 텍스트로 바꿔 읽게 하는 대신, 문서 페이지를 사진처럼 그대로 보여주고 찾게 한다.

ColPali 계열 모델이 이 접근의 대표 사례다. 문서를 OCR로 텍스트화하지 않고 페이지 이미지 자체를 임베딩(벡터로 변환)해서, 질문과 문서 이미지를 직접 비교한다. 이 방식이 표·그림이 섞인 문서에서 텍스트 전용 검색보다 강점을 보인다는 것이 ViDoRe 시리즈가 반복해서 확인해 온 결과다.

## 동작 원리

1. 문서 페이지를 OCR로 텍스트화하지 않고, 페이지 이미지 자체를 시각-언어 모델(Vision-Language Model)로 인코딩한다.
2. 질문(쿼리)도 같은 임베딩 공간으로 인코딩한 뒤, "늦은 상호작용(Late Interaction)" 방식으로 질문과 문서 이미지 조각(패치) 사이의 세밀한 유사도를 계산한다.
3. ViDoRe V3는 여기서 한 단계 더 나아가 검색(어느 문서가 관련 있는가) → 지역화(문서의 어느 부분·바운딩 박스가 근거인가) → 답변 생성(실제로 맞는 답을 만드는가)까지 하나의 파이프라인으로 묶어 평가한다.
4. 사람이 직접 만들고 검증한 3,099개 질의를 6개 언어로 제공해, AI가 생성한 합성 질문에 의존하던 기존 방식의 한계를 보완한다.

## 구체 예시·사례

감사 실무를 예로 들면, 스캔된 세금계산서 더미에서 "특정 거래처의 3월 공급가액 합계"를 찾는 상황을 생각할 수 있다. 텍스트 전용 RAG라면 OCR이 표의 행·열 구조를 깨뜨려 엉뚱한 값을 가져올 위험이 있다. ViDoRe 방식의 시각 검색기는 표를 이미지 그대로 인식하기 때문에, 어느 셀이 어느 거래처·달에 해당하는지 구조를 유지한 채 찾아낼 가능성이 높다.

ViDoRe V3의 평가 결과, 시각 검색기가 텍스트 검색기보다 전반적으로 우수했고, 시각 정보와 텍스트를 함께 쓰는 하이브리드 방식이 답변 생성 품질을 높였다. 다만 표·그림 같은 비텍스트 요소, 열린 질문(정답이 한 곳에 명확히 있지 않은 질문), 세밀한 시각적 근거 제시에서는 여전히 한계가 있었다.

## 비슷한 것과 비교

| 구분 | ViDoRe V1 | ViDoRe V2 | ViDoRe V3 |
|------|------|------|------|
| 문제점/개선점 | 상위 모델이 90% 이상 점수를 받아 성능 포화 | 문맥이 가려진 질의·긴 교차 문서 질의 도입, 4개 다국어 데이터셋 | 10개 데이터셋, 약 2만 6천 페이지, 3,099개 사람 검증 질의(6개 언어) |
| 평가 범위 | 문서 검색 정확도 위주 | 더 어려운 실전형 검색 시나리오 | 검색+지역화(근거 위치)+답변 생성까지 종단 평가 |
| 질의 생성 방식 | 초기 벤치마크 | 합성+사람 검토 혼합 | 사람이 직접 만들고 검증 |

기존 텍스트 전용 RAG 벤치마크(BEIR·MTEB 등)와 비교하면, ViDoRe 계열은 "글자만 있는 문서"가 아니라 표·차트·손글씨가 섞인 "시각적으로 복잡한 문서"를 다뤄야 하는 업무(감사·회계·법무)에 훨씬 직접적으로 대응한다는 점에서 선택 기준이 갈린다.

## 왜 지금 중요한가

ViDoRe V3는 프랑스 ILLUIN Technology가 NVIDIA와 함께 공개한 벤치마크로, 2026년 1월 논문(arXiv)과 함께 데이터셋이 공개됐다. 상업적으로도 쓸 수 있는 라이선스로 배포돼, 연구 목적을 넘어 실제 제품 평가에도 활용될 수 있다는 점이 특징이다.

RAG 시스템을 도입하려는 기업 입장에서 "우리 업무 문서(표·스캔본이 많은 문서)에서 이 검색 시스템이 실제로 잘 작동하는가"를 검증할 표준 잣대가 마땅치 않았는데, ViDoRe V3가 그 공백을 메우는 벤치마크로 언급되고 있다.

- [ViDoRe V3: A Comprehensive Evaluation of Retrieval Augmented Generation in Complex Real-World Scenarios — arXiv](https://arxiv.org/abs/2601.08620)
- [ViDoRe Benchmark V3 — Hugging Face Collection](https://huggingface.co/collections/vidore/vidore-benchmark-v3)
- [ViDoRe Benchmark V2: Raising the Bar for Visual Retrieval — arXiv(직전 버전 비교용)](https://arxiv.org/abs/2505.17166)

## 회계법인 AI 직무 연결 포인트

감사 증거로 쓰이는 문서 상당수(세금계산서, 계약서, 재무제표 스캔본, 이사회 의사록)는 표·도장·손글씨가 섞여 있어 텍스트 추출만으로는 정보가 깨지기 쉽다. 멀티모달 RAG는 이런 문서를 이미지 그대로 검색·대사할 수 있게 해, 감사인이 방대한 증빙 더미에서 특정 거래를 찾는 시간을 줄일 수 있다.

또한 지역화(어느 부분이 근거인지 위치까지 짚어주는 기능)는, AI가 찾아준 답이 실제로 어느 페이지·어느 셀에서 나왔는지 사람이 바로 확인할 수 있게 해준다. 이는 감사 증거의 추적 가능성(Traceability) 요구와 직결된다.

면접에서는 "AI 기반 문서 검색을 감사 증거 확인에 쓸 때 가장 우려되는 지점이 무엇인가"라는 질문에, 비텍스트 요소·열린 질문에서 여전히 한계가 있다는 ViDoRe V3의 발견을 근거로, 사람의 최종 검증 절차가 반드시 병행돼야 한다고 답할 수 있다.

## 핵심 용어·논쟁

- **RAG(검색증강생성)** — 답을 생성하기 전에 외부 문서를 먼저 검색해 근거로 삼는 방식.
- **ColPali** — 문서 페이지 이미지를 그대로 임베딩해 검색하는 시각 문서 검색 모델 계열.
- **늦은 상호작용(Late Interaction)** — 질의와 문서를 각각 여러 조각으로 나눠 세밀하게 유사도를 비교하는 검색 방식.
- **지역화(Localization)** — 답의 근거가 문서의 어느 위치(바운딩 박스)에 있는지 짚어주는 기능.

시각 검색기가 텍스트 검색기보다 전반적으로 우수하다는 결과가 나왔지만, 텍스트 검색·리랭킹을 함께 쓰는 하이브리드 방식이 여전히 필요하다는 점에서 "시각 검색이 텍스트 검색을 완전히 대체하는가"는 아직 열린 논쟁이다.

## 자료 깊이 읽기

### ViDoRe V3: A Comprehensive Evaluation of RAG in Complex Real-World Scenarios — arXiv 논문 — 영어, 학술논문, 고급
ILLUIN Technology와 NVIDIA가 2026년 1월 공개한 원 논문이다. 10개 데이터셋, 약 2만 6천 문서 페이지, 3,099개의 사람이 직접 만들고 검증한 질의(6개 언어)로 구성됐다는 벤치마크 규모를 밝힌다. 기존 벤치마크가 합성 질의에 의존했던 것과 달리 검색 관련성·바운딩 박스 위치·검증된 정답까지 사람이 주석을 달았다는 점을 강조한다. 평가 결과 시각 검색기가 텍스트 검색기를 능가하고, 늦은 상호작용 모델과 텍스트 리랭킹이 성능을 크게 끌어올리며, 하이브리드(시각+텍스트) 맥락이 답변 생성 품질을 높인다는 점을 확인했다. 다만 비텍스트 요소, 열린 질의, 세밀한 시각적 근거 제시에서는 현재 모델들이 여전히 어려움을 겪는다고 밝힌다.

### ViDoRe Benchmark V3 — Hugging Face 공식 컬렉션 — 영어, 공식 데이터셋 페이지, 중급
벤치마크 데이터셋과 리더보드가 실제로 공개된 허깅페이스 공식 페이지다. 상업적으로 이용 가능한 라이선스로 배포된다는 점과, V1·V2에 이어 세 번째 세대 벤치마크라는 계보를 확인할 수 있다. 실제로 모델을 평가해보려는 실무자가 코드·데이터에 바로 접근할 수 있는 창구 역할을 한다.

## 자가 점검 질문

1. 텍스트 전용 RAG가 표·이미지가 섞인 문서에서 정보를 놓치는 이유는 무엇이며, ViDoRe 방식은 이를 어떻게 보완하는가?
2. ViDoRe V3가 검색·지역화·답변 생성을 하나로 묶어 평가하는 방식이, 검색 정확도만 보는 기존 벤치마크와 비교해 어떤 실무적 의미를 갖는가?
3. 감사 증거 검토에 멀티모달 RAG를 도입할 때, ViDoRe V3가 지적한 "비텍스트 요소·열린 질의 한계"를 어떻게 보완할 수 있는가?
