## 다루는 하위 주제 순서

### 1. 사전학습 기반 모델(Foundation Model)이란
- 텍스트 데이터를 대량으로 학습시켜 "빈칸 채우기"나 "다음 글 예측" 방식으로 말을 잘하도록 훈련시킨 모델을 기반 모델이라 부른다.
- 기반 모델은 텍스트를 유창하게 생성하는 데는 특화돼 있지만, 특정 업무를 "하고 싶어 하는" 목적성은 없다고 설명한다.
- 비유: 기반 모델은 초·중·고 정규교육 과정을 마친 사람과 같다 — 일반 소양은 갖췄지만 특정 회사 업무는 모른다.

### 2. 기반 모델을 만드는 비용
- 예시로 메타의 라마 2(Llama 2)를 언급하며, 기반 모델 하나를 만드는 데 대략 1천억 원 규모의 비용이 들어갔을 것으로 추산한다고 설명한다(발표자의 어림값이며 공식 수치는 아님, 직접 재확인 필요).
- 이런 막대한 비용 때문에 기반 모델을 처음부터 새로 만드는 것은 소수의 거대 자본만 가능하다고 짚는다.

### 3. 파인튜닝(Fine-Tuning)이란 — "입사교육" 비유
- 파인튜닝을 신입사원이 회사에 입사한 뒤 받는 입사교육에 비유한다: 기반 지식(정규교육)은 이미 갖췄으니, 회사 업무에 필요한 부분만 추가로 가르치는 것.
- 초·중·고·대학 과정을 회사마다 새로 시키는 것이 비효율적이듯, 기반 모델을 매번 새로 만드는 대신 이미 잘 훈련된 기반 모델에 미세조정만 얹는 방식이 합리적이라고 설명한다.

### 4. 분야별 파인튜닝 사례
- 구글이 2021년 만든 기반 모델 패스웨이(Pathways)를 언어모델(PaLM)로 만들고, 여기서 다시 의학 특화(Med-PaLM), 보안 특화(Sec-PaLM)로 파인튜닝한 사례를 소개한다.
- 수학 계산에 특화된 미네르바(Minerva)도 같은 방식으로 파인튜닝된 모델이라고 설명하며, 이런 특화 모델들은 파인튜닝 데이터 자체가 크지 않아도 기반 모델 내부에 이미 있는 잠재력을 "가이드"만 잡아주는 방식으로 만들어진다고 강조한다.
- 하나의 기반 모델 위에 여러 특화 모델을 파생시키는 것이 일반적인 산업 패턴이라고 정리한다.

### 5. 왜 LoRA가 필요한가
- 파인튜닝도 결국 기반 모델 위에서 학습을 시켜야 하므로 비용·시간 부담이 있다고 지적한다.
- 구글·네이버 같은 거대 자본이 없는 일반 기업·연구소에는 더 경량화된 파인튜닝 방법이 현실적으로 필요했고, 그래서 나온 것이 LoRA(Low-Rank Adaptation of LLM)라고 소개한다.

### 6. LoRA의 동작 방식(발표자 설명 수준)
- 사전훈련된 모델은 그대로 두고, 옆에 작은 레이어(어댑터)를 붙여서 그 부분만 추가 훈련시키는 방식이라고 설명한다.
- 결과물인 어댑터 모델은 용량이 작다(발표자는 "코드로 100MB 정도"라고 언급 — 기반 모델의 수십 기가바이트와 대비되는 규모감을 전달하려는 취지의 발언으로, 정확한 수치는 모델·설정마다 다르므로 직접 재확인 필요) 훈련도 빠르다고 강조한다.
- 의학·교육·금융처럼 특정 분야에 특화시킬 때 LoRA를 쓰는 경우가 많다고 설명한다.

### 7. 산업 현장에서의 파인튜닝 지원
- 래블업 같은 AI 엔지니어링 플랫폼 기업은 백엔드 AI 기능이 통합돼 있어, 기업들이 별도 비용 없이 파인튜닝 관련 기능을 활용할 수 있도록 지원한다고 언급한다.

### 8. LLM 파인튜닝의 "레드오션화" 전망
- 발표자는 LLM 분야가 빠르게 "레드오션"이 될 것이라 전망한다 — 기반 모델을 만드는 데는 여전히 큰돈이 필요하지만, 파인튜닝 자체의 기술적 난이도는 생각보다 낮고 관련 기술이 공개돼 있어 접근 장벽이 낮다는 이유에서다.
- 웬만한 IT 회사들이 한 번씩은 파인튜닝을 시도해볼 것이라 예상하며, 기술적으로는 레드오션이 되더라도 "재미있는 데이터로 재미있는 사업 기회를 찾는" 서비스화 영역에서는 여전히 블루오션이 남아 있다고 정리한다.
- 예시로 스테이블 디퓨전(Stable Diffusion) 시대에 사진 몇 장으로 얼굴을 보정해 신분증·여권 사진을 재발급받는 서비스가 뜻밖의 수요를 만들어낸 사례를 든다.

## 실무 팁·수치 관련 유의사항
- 영상에서 언급된 "라마2 학습 비용 약 1천억 원", "LoRA 어댑터 용량 약 100MB" 등은 발표자의 구두 어림값으로, 공식 수치가 아니므로 실제 활용 시 별도로 재확인이 필요하다.
- 영상은 QLoRA의 4비트 양자화 같은 세부 기술보다는 "왜 LoRA가 필요한가"라는 배경과 산업적 맥락 설명에 집중한다. QLoRA의 구체적인 양자화 기법을 더 깊이 알고 싶다면 별도 자료를 참고해야 한다.
