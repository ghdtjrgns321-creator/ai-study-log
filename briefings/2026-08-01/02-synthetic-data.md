# 오늘의 AI 개념: 합성 데이터(Synthetic Data)

> 작성일: 2026-08-01 · 분류: ai-concept

## 한 줄 정의

합성 데이터는 실제 사건을 기록한 데이터가 아니라 컴퓨터 프로그램이나 AI 모델이 통계적으로 진짜와 비슷하게 만들어낸 인공 데이터다.

## 쉬운 설명

사진 촬영과 그림을 비교하면 이해하기 쉽다. 실제 데이터는 카메라로 찍은 사진이고, 합성 데이터는 화가가 그 사진을 보고 똑같이 그린 그림이다. 그림은 진짜 풍경이 아니지만, 잘 그리면 사진과 통계적으로 구분하기 어려울 만큼 비슷하게 만들 수 있다.

AI 모델을 학습시키려면 대량의 데이터가 필요한데, 실제 데이터는 수집 비용이 크고 개인정보가 섞여 있으며 희귀한 사례(예: 드문 유형의 사기 거래)는 애초에 표본이 적다. 합성 데이터는 이 세 가지 문제를 동시에 우회한다 — 원하는 만큼 만들 수 있고, 실존 인물·기업 정보가 없어 프라이버시 부담이 적으며, 드문 사례를 의도적으로 많이 만들어낼 수 있다.

기존의 "데이터 라벨링"과는 다른 개념이다. 라벨링은 이미 존재하는 실제 데이터에 사람이 정답표(라벨)를 붙이는 작업이고, 합성 데이터 생성은 데이터 자체를 처음부터 인공적으로 만들어낸다는 점에서 출발선이 다르다.

## 동작 원리

```
① 생성 방식 선택
   ├─ 시뮬레이션: 게임 엔진·3D 모델링으로 가상 환경을 만들고 자동으로 정답 라벨을 붙임
   ├─ 생성 모델: GAN(생성적 적대 신경망)·확산 모델·LLM이 실제 데이터의 통계 분포를 학습해 새 샘플을 생성
   └─ 신경 재구성: 실제 2D 영상 등을 AI로 3D·다른 형태로 재구성
② 품질 검증
   → 실제 데이터와의 "도메인 갭"(현실과의 괴리)을 줄이기 위해
     생성 조건을 무작위로 바꿔가며 다양성을 확보(도메인 무작위화)
③ 다운스트림 활용
   → 모델 학습(파인튜닝), 평가셋 구축, 엣지 케이스 보강, 민감정보 대체용으로 사용
```

핵심 리스크는 "모델 붕괴(Model Collapse)"다. AI가 만든 합성 데이터로 다시 AI를 학습시키는 과정을 반복하면, 원본 데이터의 희귀하고 다양한 특성이 점점 사라지고 모델이 스스로 만든 편향을 답습하는 현상이 발생할 수 있다. 이를 막기 위해 실제 데이터를 일정 비율 섞고(real-data seed), 서로 다른 생성 모델을 혼합해 쓰고, 생성된 데이터셋의 다양성을 별도로 점검하는 방식이 쓰인다.

## 구체 예시·사례

카드사 아메리칸 익스프레스는 사기 탐지 모델을 개선하는 데 합성 데이터를 활용한 것으로 알려져 있다. 실제 사기 거래는 전체 거래 중 극히 일부라서 학습 데이터가 부족한데, 정상 거래 패턴을 통계적으로 학습한 뒤 이를 변형해 다양한 유형의 가상 사기 패턴을 대량으로 만들어 학습에 투입하는 방식이다. 의료 분야에서는 AI 헬스케어 기업 큐라이(Curai)가 약 40만 건의 시뮬레이션 진료 사례로 진단 모델을 훈련한 사례가 있다.

## 비슷한 것과 비교

| 구분 | 합성 데이터 | 데이터 라벨링 | 데이터 익명화·비식별화 |
|---|---|---|---|
| 출발점 | 데이터 자체를 새로 생성 | 이미 존재하는 실제 데이터 | 이미 존재하는 실제 데이터 |
| 목적 | 데이터 부족·편향·프라이버시 문제 해결 | 지도학습용 정답표 부착 | 개인정보를 가리되 원본 구조는 유지 |
| 리스크 | 도메인 갭, 모델 붕괴 | 라벨러 간 일관성, 비용 | 재식별 가능성 |
| 회계·감사 적용 | 이상거래 시뮬레이션 학습 데이터 | 실제 감사증거에 이상·정상 라벨 부착 | 고객 재무데이터를 외부 벤더에 보낼 때 비식별화 |

선택 기준: 데이터가 아예 부족하거나 민감정보라 원본을 못 쓴다면 합성 데이터를, 원본 데이터는 있지만 정답표만 없다면 라벨링을, 원본을 그대로 쓰되 신원만 가리고 싶다면 비식별화를 택한다.

## 왜 지금 중요한가

에포크 AI(Epoch AI) 연구진은 고품질 언어 학습 데이터가 2026~2032년 사이 고갈될 수 있다고 예측한 바 있으며, 이 데이터 부족 문제가 합성 데이터 채택을 가속화하는 배경으로 꼽힌다. 동시에 프런티어 모델의 생성 비용이 낮아지면서, 과거라면 비쌌을 고품질 합성 데이터 생성이 이제는 상대적으로 저렴한 컴퓨팅 자원으로 가능해졌다는 분석도 나온다.

바로 오늘 다룬 다른 주제인 커서 컴포저 2.5도 "기능 삭제 퍼즐"이라는 합성 학습 과제를 컴포저 2 대비 25배 늘려 코딩 모델을 훈련시켰다고 밝혔는데, 이는 합성 데이터가 코딩 에이전트 학습의 핵심 방법론으로 자리 잡고 있음을 보여주는 실제 사례다.

## 회계법인 AI 직무 연결 포인트

이상거래·부정(Fraud) 탐지 모델을 학습시킬 때 실제 부정 사례는 표본이 매우 적다는 근본적 한계가 있다. 정상 거래 데이터를 기반으로 다양한 유형의 가상 이상거래 패턴을 합성해 학습 데이터를 보강하면, 실제로는 아직 한 번도 나타나지 않은 새로운 유형의 부정까지 탐지 모델이 대비할 수 있게 된다.

고객사의 재무 데이터를 외부 AI 벤더나 클라우드 서비스에 보내 분석을 맡겨야 할 때, 원본 대신 통계적 특성을 보존한 합성 재무데이터를 만들어 프로토타입 검증에 활용하면 기밀유지계약(NDA)·개인정보보호 리스크를 낮출 수 있다. 다만 합성 데이터가 원본의 통계적 특성을 얼마나 정확히 재현했는지 자체가 검증 대상이 되므로, 합성 데이터 품질 검증 절차 역시 감사 대상에 포함될 수 있다.

AI 모델 학습에 합성 데이터가 쓰였다는 사실 자체가, AI 모델카드·데이터 리니지 감사(2026-07-20 브리핑 참고)에서 점검해야 할 새로운 항목이 되고 있다 — "이 모델이 어떤 비율로 합성 데이터를 학습했는지"가 모델 신뢰도 평가의 한 축이 되기 때문이다.

## 핵심 용어·논쟁

- **모델 붕괴(Model Collapse)** — AI가 생성한 합성 데이터로 AI를 반복 학습시키면 데이터의 다양성이 줄어들고 편향이 누적되는 현상.
- **도메인 갭(Domain Gap)** — 합성 데이터와 실제 데이터 사이의 통계적·구조적 차이.
- **도메인 무작위화(Domain Randomization)** — 합성 데이터 생성 조건을 다양하게 무작위로 바꿔 도메인 갭을 줄이는 기법.
- **차등 정보보호(Differential Privacy)** — 합성 데이터가 원본의 특정 개인을 재식별하지 못하도록 수학적으로 보장하는 기법.

합성 데이터의 가장 큰 논쟁은 "품질을 어떻게 검증할 것인가"다. 실제 데이터와 통계적으로 비슷해 보여도 미세한 패턴 왜곡이 누적되면 모델 성능이 서서히 저하될 수 있는데, 이 저하는 즉각 드러나지 않아 사후에 발견하기 어렵다는 문제가 지적된다.

## 자료 깊이 읽기

### 합성 데이터란? — 한국어/공식 기업 블로그/초급
NVIDIA 코리아 공식 블로그. 합성 데이터를 "컴퓨터 시뮬레이션이나 알고리즘이 실제 데이터의 대안으로 생성하는 주석이 달린 정보"로 정의하고, 시뮬레이션·생성모델·신경 재구성 세 가지 생성 방식, Ford·BMW의 자율주행 학습 사례, Amazon Robotics의 물류 훈련 사례, American Express의 사기 탐지 개선 사례, 라벨링 비용을 100분의 1 수준으로 낮추는 비용 효율성과 도메인 갭이라는 한계를 함께 다룬다.

### Synthetic Data for LLM Fine-Tuning in 2026 — 영어/블로그/중급
합성 데이터 생성이 2026년 주류 방법론으로 자리 잡은 배경(프런티어 모델의 생성 비용 하락, 실데이터 고갈 전망)을 다루고, 시드 대화 작성 → Self-Instruct로 확장 → 판단 모델로 DPO 선호 쌍 생성 → 품질 필터링 → 학습이라는 2026년형 표준 파이프라인을 설명한다. 모델 붕괴 문제와 마이크로소프트·허깅페이스·앤트로픽 등이 검증 중인 완화 방법(교사 모델 혼합, 실데이터 시드 포함, 다양성 점검)도 소개한다.
