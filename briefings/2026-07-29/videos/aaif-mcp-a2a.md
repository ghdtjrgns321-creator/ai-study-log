## 다루는 하위 주제 순서

1. **왜 MCP가 필요한가 — USB-C 비유**
   AI가 점점 더 많은 외부 시스템과 연결되어야 하는 시대가 되면서, 기기마다 케이블이 다르던 시절 USB-C가 통합했던 것처럼 AI 연결에도 표준이 필요해졌다는 문제의식에서 출발한다. 그 표준이 Anthropic이 만든 MCP(Model Context Protocol)라고 소개한다.

2. **MCP 이전의 문제**
   AI 모델이 외부 데이터나 API 문서와 연결될 때마다 매번 다른 방식으로 소프트웨어를 개발·세팅해야 했던 비효율을 지적한다. MCP는 이 연결 방식 자체를 표준화한 "세상을 연결하는 하나의 단자"라고 요약한다.

3. **MCP의 두 축 — 클라이언트와 서버**
   ```
   [MCP 클라이언트]              [MCP 서버]
   ChatGPT / Claude / Cursor  <--> 정보·기능을 제공하는 서비스 주체
   (사용자가 쓰는 AI 도구)          (JSON-RPC 기반 메시지로 통신)
   ```
   서버를 직접 구축할 수도 있고, 이미 공개된 서버(Booking.com, Canva, Coursera, Figma 등)에 연결해 쓸 수도 있다고 설명한다.

4. **MCP 서버의 3대 구성 요소**
   ```
   MCP 서버 내부
   ├─ 리소스(Resource)   : 서버가 담고 있는 실제 데이터(문서, 메일 등)
   ├─ 툴(Tool)           : 실제 액션을 수행하는 도구(예: getWeather)
   └─ 샌드박스(Sandbox)  : 모델이 툴·리소스를 안전하게 실행하는 격리 공간
   ```
   AI가 툴을 스스로 찾아 호출하고, 리소스를 가져오고, 그 결과를 근거로 답을 만드는 흐름을 이 세 요소로 설명한다.

5. **확산 현황**
   MCP는 Anthropic이 만들었지만 Google, Microsoft, OpenAI 등 여러 업체가 이 표준을 따라 연결하고, 인증 방법까지 함께 논의하고 있다고 언급한다(영상 시점인 2025년 10월 기준 서술).

6. **실습 데모 — ChatGPT에서 커넥터 연결하기**
   - ChatGPT Plus(월 20달러) 이상 계정에서만 사용 가능하다는 점을 먼저 안내한다.
   - 설정 → Apps & Connectors 메뉴에서 Booking.com, Gmail, Google 주소록 등 커넥터를 연결하는 과정을 시연한다.
   - "제주도에서 2025년 10월 20일~25일 일정에 맞는 오성급 호텔 추천해줘"라고 질문하면, ChatGPT가 연결된 Booking.com 커넥터를 통해 실시간 검색 결과와 이미지를 가져와 답하는 장면을 보여준다.
   - 이어서 "최근 Gmail 메일 10개 제목과 내용 보여줘"라는 요청도 동일한 방식으로 처리되는 것을 시연한다.

7. **커스텀 MCP 서버 직접 추가하기**
   설정 → 고급 설정 → 개발자 모드에서 이름·설명·접속 주소·인증 방법을 입력해 서버를 직접 등록하는 방법을 안내한다. 예시로 Microsoft Learn 문서 사이트를 MCP 서버로 연결해, 마이크로소프트 기술 문서 기반 질의응답이 가능해지는 장면을 보여준다. 단, 기업 계정 설정에 따라 개발자 모드가 비활성화되어 있을 수 있다고 언급한다.

8. **마무리 — MCP의 의미**
   MCP를 통해 ChatGPT·Claude·Gemini 같은 AI 도구가 "하나의 플랫폼"이 되어, 연결하는 커넥터가 늘어날수록 할 수 있는 일이 무한히 확장된다고 정리한다. 어떤 커넥터의 어떤 툴을 쓸지는 AI 모델 스스로 판단해 선택한다는 점을 강조하며 마무리한다.

## 실무 팁 재확인
- ChatGPT의 MCP 커넥터 기능은 무료 플랜에서는 사용할 수 없고 최소 ChatGPT Plus(유료) 이상이 필요하다는 조건은 영상 원문 그대로다.
- 기업(엔터프라이즈) 계정은 관리자 설정에 따라 개발자 모드(커스텀 MCP 서버 등록)가 막혀 있을 수 있다는 점도 원문 그대로 보존한다.
