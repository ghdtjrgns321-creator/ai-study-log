# 오늘의 AI 개념: SK텔레콤 A.X K2(에이닷엑스 케이투)

> 작성일: 2026-08-02 · 분류: trend

## 한 줄 정의

A.X K2는 SK텔레콤이 자체 개발해 2026년 7월 29일 오픈소스로 공개한 6,880억(688B) 파라미터 규모의 국산 파운데이션 AI 모델로, 국내 산업 현장과 국방·바이오 분야에 특화된 활용을 목표로 한다.

## 쉬운 설명

지금까지 국내 기업들은 챗GPT·클로드 같은 해외 프런티어 모델을 API로 빌려 쓰거나, 네이버·LG 같은 소수 기업만 자체 대형 모델을 만들어왔다. SK텔레콤은 통신사이면서도 이 대열에 합류해, 2025년 519B 규모의 A.X K1에 이어 이번에 688B 규모의 2세대 모델을 내놨다.

비유하면, 지금까지 국내 기업 대부분이 해외에서 완제품 엔진을 수입해 자동차를 조립했다면, SK텔레콤은 자체 엔진 설계 2세대 버전을 내놓은 셈이다. 이전 세대보다 더 크고 정교해졌을 뿐 아니라, 처음부터 "제조 현장·군 장비·신약 개발" 같은 특정 산업 용도에 맞춰 튜닝했다는 점이 특징이다.

기존의 범용 프런티어 모델과의 차이는 목적성에 있다. 오픈AI·앤트로픽의 최신 모델이 코딩·대화·추론 전반에서 최고 성능을 노린다면, A.X K2는 처음부터 "국내 산업 현장에서 바로 쓸 수 있는가"를 최우선 목표로 설계됐고, 오픈소스로 공개해 기업들이 자체 인프라에 얹어 커스터마이징하기 쉽게 만들었다.

## 동작 원리

```
① SGA(Sparse Gated Attention) 구조 적용
   → 게이티드 어텐션(헤드별 출력 게이트)으로 학습 안정성 확보
   → 경량 인덱서가 질의마다 핵심 토큰 상위 k개(k=2048)만 골라
     주의를 집중 → 긴 문맥에서도 연산량을 크게 줄임
② 게이티드 트랜스포머 블록 — MoE(전문가 혼합) 구조에 SGA(어텐션)와
   게이티드 정규화(GN)를 결합해 대규모 학습 중 안정성과
   저정밀도 서빙 효율을 동시에 확보
③ 벤치마크 검증 — 국내외 14개 벤치마크 평균 32.2%p,
   장문이해·에이전트 평가에서 약 83.9%p 향상(전작 A.X K1 대비)
④ 오픈소스 공개 — 허깅페이스를 통해 모델 가중치 공개 →
   기업이 자체 데이터로 파인튜닝·온프레미스 배포 가능
```

핵심은 ①이다. 긴 문서를 통째로 넣고 추론시킬 때, 모든 토큰을 다 보는 대신 질의와 관련성이 높은 일부만 골라 계산량을 줄이는 방식으로 "정확도는 유지하면서 비용은 낮추는" 것을 노렸다.

## 구체 예시·사례

SK텔레콤은 제조 분야에서 KG스틸·코넥과 협업해 현장 실증을 진행 중이며, 국방부와는 A.X K1 기반 양자화 모델 3종을 개발해 육·해·공군과 해병대 산하 부대에 보급할 계획이라고 밝혔다. 바이오 분야에서는 SK바이오팜과 협력해 신약 후보물질 탐색 기간을 기존 1~2년에서 5개월로 단축하는 것을 목표로 한다고 전했다(모두 SK텔레콤 자체 발표 기준으로, 독립적 성과 검증은 아직 확인되지 않았다).

## 회계법인 AI 직무 연결 포인트

국내 회계법인·감사 대상 기업이 다루는 재무·감사 데이터는 대외비 성격이 강해, 해외 클라우드 기반 API로 전송하는 데 보수적인 경우가 많다. A.X K2처럼 오픈웨이트로 공개돼 온프레미스나 사내 폐쇄망에 직접 설치할 수 있는 국산 모델은, 이런 데이터 반출 우려를 해소하면서도 AI 분석 역량을 확보할 대안이 될 수 있다. 실제로 국내 감사 대상 기업 중 방위산업·에너지·바이오처럼 보안 민감도가 높은 업종일수록 이런 온프레미스형 모델의 실무 채택 가능성이 높다.

또한 SK텔레콤이 제조·국방·바이오 등 특정 산업에 맞춰 모델을 튜닝했다는 접근은, 회계법인이 감사 전용 AI를 도입할 때도 "범용 모델을 그대로 쓸 것인가, 회계기준·감사방법론에 맞춰 별도로 파인튜닝할 것인가"를 고민하게 만드는 참고 사례다. 오픈웨이트 모델의 확산은 회계법인이 벤더 종속 없이 자체적으로 감사 특화 모델을 파인튜닝할 수 있는 선택지를 넓혀준다는 점에서도 눈여겨볼 만하다.

## 핵심 용어·논쟁

- **스파스 게이티드 어텐션(SGA, Sparse Gated Attention)** — 질의와 관련성이 높은 일부 토큰만 선별해 주의를 집중함으로써 긴 문맥 처리 연산량을 줄이는 어텐션 구조.
- **오픈웨이트(Open-weight)** — 모델의 학습된 가중치 파일을 공개해, 누구나 내려받아 자체 인프라에서 구동·수정할 수 있게 하는 공개 방식(학습 코드·데이터까지 전부 공개하는 완전 오픈소스와는 구분).
- **주권 AI(Sovereign AI)** — 특정 국가·기업이 외부 벤더에 의존하지 않고 자국·자사 데이터로 학습한 AI 모델을 자체 보유하려는 전략.
- **양자화(Quantization)** — 모델의 연산 정밀도를 낮춰 크기와 연산량을 줄이는 기법. 국방부용 A.X K1 기반 모델처럼 제한된 하드웨어(현장 장비 등)에 배포할 때 흔히 쓰인다.

국내에서 SKT·LG·네이버가 각자 대형 모델을 경쟁적으로 내놓는 것에 대해, 중복 투자라는 비판과 데이터 주권 확보를 위한 필수 투자라는 옹호가 엇갈린다. 이 논쟁은 아직 결론이 나지 않은 진행형 쟁점이다.
