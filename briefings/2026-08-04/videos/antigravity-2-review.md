## 도입 — 왜 다시 촬영하게 됐는가

발표자는 구글 I/O에서 안티그래비티 2.0이 공개되자, 이전에 멤버십용으로 올렸던 1.0 강의 영상을 완전히 새로 찍어야 하는 상황이 됐다고 밝힌다. 업그레이드 직후 커뮤니티 반응은 오히려 부정적이었는데, 실제로 어떻게 달라졌고 장단점이 무엇인지 직접 설치해 확인하는 형식으로 영상이 진행된다.

## 1. 설치와 구성 요소

안티그래비티 사이트에 들어가면 macOS·Windows·Linux용 데스크톱 앱을 내려받을 수 있고, 그 아래 새로 CLI도 추가됐다고 소개한다. 기존 제미나이 CLI는 2026년 6월 종료되며 안티그래비티 CLI로 흡수됐다. "안티그래비티가 없어진다"는 루머가 있었지만, 실제로는 완전히 새로운 형태로 재편되며 오히려 안티그래비티라는 이름으로 통합되는 흐름이라고 설명한다.

제공되는 구성 요소는 데스크톱 앱, CLI, SDK, 그리고 기존 방식대로 유지되는 IDE(에디터) 네 가지다. 다만 IDE는 원래 안티그래비티 1.0이 VS Code를 포크해서 만든 것이었는데, 2.0으로 강제 업그레이드되면서 기존에 구축해둔 워크플로우·설정이 사라지는 단점이 있었다고 지적한다.

설치 과정에서 플러그인 패키지 컬렉션을 선택하는 화면이 나오는데, 안드로이드·모던웹 가이던스·안티그래비티 SDK·파이어베이스·크롬 데브툴 등 구글 개발자 제품과 에이전트를 연동해주는 스킬·MCP 패키지 모음이라고 설명한다. 처음 설치 시 오류가 났었지만 재설치 후에는 문제없이 진행됐다고 언급한다.

## 2. UI 변화 — 워크스페이스에서 프로젝트로

가장 큰 변화로 "워크스페이스"라는 개념이 "프로젝트"로 이름이 바뀌었다는 점을 꼽는다. 예전의 에이전트 매니저 UI와 유사한 형태를 유지하면서도, 프로젝트 단위로 관리하는 방식으로 재편됐다. 모델 사용량 제한(리밋) 정보도 화면에 표시되는데, 제미나이 3.5가 새로 들어가면서 초기에는 리밋이 짧아졌다가 이후 사용량이 두 배로 늘어나는 이벤트가 있었다고 언급한다.

지원 모델 목록에서 제미나이 3.5 플래시(하이·미디엄), 기존 3.1 프로(하이·로우), 클로드 소네 4.6, 클로드 오퍼스 4.6, GPT-OSS 120B를 확인할 수 있었는데, 이전에 있던 제미나이 3.0 플래시 모델은 목록에서 빠졌다고 지적한다. 토큰을 아낄 수 있는 저비용 모델로는 GPT-OSS 120B가 유일하지만 성능이 낮아 실질적으로 토큰을 더 많이 소모하게 되는 문제가 있다고 평가한다.

새로 추가된 기능으로 스케줄 태스크(예약 작업)를 소개한다. 특정 시각에 정해진 프롬프트를 반복 실행하도록 예약할 수 있는 기능이다.

## 3. 실전 시연 — 오케스트레이터와 서브에이전트

로컬 환경을 선택해 폴더를 지정한 뒤, 다음과 같이 지시한다: "AI로 약 먹을 시간을 알려주는 서비스를 만들고 싶은데 오케스트레이터와 서브에이전트를 사용해서 병렬로 작업해줘. 필요한 스킬은 기존 것 중에서 가져다 쓰고, 없으면 만들어서 사용해라."

에이전트는 먼저 계획(플랜)을 세워 제출(submit)을 요구한다. 승인하자 UI/UX 담당 서브에이전트와 로직·AI 스페셜리스트를 담당하는 서브에이전트 두 개가 동시에 생성되어 병렬로 작업을 시작한다. 발표자는 이 화면이 클로드 코드의 "에이전트 뷰" 기능과 비슷하다고 언급하며, 오케스트레이터가 서브에이전트들을 한 화면에서 관리하는 구조에 만족감을 표한다.

작업 완료 후 최종 보고서가 만들어지고, 브라우저 사용 권한을 켜자 에이전트가 직접 브라우저를 띄워 완성된 서비스를 시연한다. 복약 타임라인, 복약 등록(비타민 C·D, 오메가3 등록), 중복 성분 과다복용 경고, 상담 챗봇 기능까지 정상 작동하는 것을 확인한다. 처방전 텍스트를 붙여넣으면 자동으로 분석해 스케줄에 등록하는 기능도 시연된다.

## 4. CLI와 데스크톱 앱의 동시 편집

같은 프로젝트 폴더에서 CLI(`ag`)를 실행해도 데스크톱 앱과 같은 작업 흐름을 공유한다는 점을 시연한다. 데스크톱 앱에서 만든 결과물의 배경색을 흰색으로 바꿔달라고 CLI에서 지시하자, 데스크톱 앱 화면에도 실시간으로 변경 사항이 반영되는 것을 확인한다. 양쪽에서 동시에 같은 프로젝트를 제어할 수 있다는 점을 장점으로 꼽는다.

## 5. 총평

발표자는 촬영 전에는 커뮤니티의 부정적 반응 때문에 단점 위주로 다룰 계획이었으나, 실제 사용해보니 계속 감탄하게 됐다고 밝힌다. 특히 오류 없이 한 번에 결과물이 나오는 점, 브라우저 제어가 매끄러운 점, 무료로 사용할 수 있다는 점을 긍정적으로 평가한다. 다만 승인(proceed) 버튼을 계속 눌러줘야 하는 번거로움이 있고, 예전에는 자동 승인 설정이 있었는데 2.0에서는 해당 설정을 찾지 못했다고 아쉬움을 표한다.

결론적으로 안티그래비티 2.0은 클로드 코드나 코덱스와 비교해도 큰 차이가 없으며, 오히려 브라우저 제어와 코딩 결과물의 깔끔함 면에서 만족스럽다고 평가하며 영상을 마무리한다.

## 확인 필요 표시

- "제미나이 3.5 사용량 두 배 이벤트", "자동 승인 설정 위치" 등은 영상 내 구어체 언급을 그대로 옮긴 것으로, 공식 문서를 통한 재확인이 필요하다.
- 모델 목록·성능 평가는 발표자 개인 사용 경험에 근거한 주관적 의견이다.
